# Demo asset provenance

The example's assets were created for SwiftVideo and are distributed with the Apache 2.0 project. No CapCut assets, third-party footage, fonts, or commercial music are included.

- `Sources/SwiftVideoEditor/Resources/Demo/coast.png`: generated using Codex's built-in ImageGen tool on 2026-10-25. The asset catalog contains an identical copy for native SwiftUI image lookup.
- `coast-wide.mp4` and `coast-close.mp4`: four-second H.264 clips created from the coastal image with slow camera movement using `Tools/GenerateDemoMedia.swift`.
- `ambient.wav`: original eight-second synthesized ambient chord, 48 kHz stereo, generated by the same Swift tool.
- System fonts are resolved at runtime and are not bundled.

Image generation prompt:

> Create a cinematic photographic still for an open-source video editor's bundled demo media. Wide landscape composition, 16:9. A dramatic Australian coastal headland at golden hour, teal ocean, white waves curling around pale sand, dark forested cliffs, warm peach sky and low sunlight. Aerial travel-film composition with the headland on the right and clear ocean on the left, richly detailed but natural, subtle film grain, beautiful atmospheric depth. No people, buildings, logos, letters, text, borders or UI. This is a standalone source image that will be animated with a slow camera pan in a sample video.

Recreate the video and audio from the saved image on macOS:

```sh
swiftc -parse-as-library Tools/GenerateDemoMedia.swift -o /tmp/swiftvideo-generate-media
/tmp/swiftvideo-generate-media Example/Sources/SwiftVideoEditor/Resources/Demo/coast.png Example/Sources/SwiftVideoEditor/Resources/Demo
```
