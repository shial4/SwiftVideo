# SwiftVideo Studio

A SwiftUI editor demonstrating SwiftVideo on iOS, macOS, and Android through Skip Fuse. All authored application and rendering code is Swift. The Android launcher is generated by Skip.

![Editor playback and tools](../Documentation/Images/editor.gif)

## Try the composition

The bundled eight-second project has four tracks:

1. Two coastal clips play sequentially as the background.
2. An animated "COASTAL ESCAPE" title accompanies a rotated image overlay.
3. A second video appears in the upper-right corner for a commentary-style layout, with timed captions below.
4. Original ambient audio fades in and out.

Select a clip in the timeline to split, trim, transform, filter, or delete it. Text edits the selected title; Audio controls volume, pan, mute, and fades. Overlay adds an image or another video. Undo and redo restore project snapshots. Export creates a new H.264/AAC MP4 at 720p or 1080p and offers sharing.

The app renders a 640x360 preview after a short debounce, then plays the resulting video. It does not render a live timeline during every gesture. Imported media picking, persistent projects, and cloud storage are outside this demo.

## Run on Apple platforms

Use Xcode with Swift 6.3 or later. Open `Example/Project.xcworkspace`, select **SwiftVideoEditor App**, and choose an iOS Simulator or My Mac. The deployment targets are iOS 17 and macOS 14.

For an Apple-only command-line build from the repository root:

```sh
xcodebuild -project Example/Darwin/SwiftVideoEditor.xcodeproj \
  -scheme 'SwiftVideoEditor App' -destination 'generic/platform=iOS Simulator' \
  -derivedDataPath Example/.build-ios -skipPackagePluginValidation \
  SKIP_ACTION=none CODE_SIGNING_ALLOWED=NO build
```

Use your normal development signing settings when installing on a physical device.

## Run on Android

Install [Skip](https://skip.dev/docs/gettingstarted/), Android Studio, a compatible JDK/Gradle, and the Swift Android SDK. Run `skip checkup` and start an API 28+ emulator or connect a device. The verification setup uses Swift Android 6.3.2, NDK r27d, Gradle 9.8.2, and an API 34 arm64 emulator.

With the emulator running, the generated Xcode scheme's Skip build phase builds and launches Android alongside iOS. Keep `SKIP_ACTION` at its normal value for that workflow. The root [Android CI workflow](../.github/workflows/android.yml) also contains the complete standalone metadata, native library, and APK build sequence.

`Sources/SwiftVideoEditor` is the shared Swift source. Do not edit generated Kotlin under `.build-*`, or hand-maintain an alternative Android renderer. The local package dependency points to the library in `..`.
